# SECTION 1: What the engine sizes, and what it refuses (owned by Associate m01)

# App surface: the Pipeline & Line Sizing Studio runs this chain live. A bore gives an area, the area and the rate give a velocity, the velocity gives a Reynolds number, the Reynolds number and the relative roughness give a friction factor, and the friction factor and the length give the loss.
- This engine sizes ONE LINE. It says what a single pipe costs in pressure and what bore it needs. A system of lines that share a header is a network solve and lives in engines/production/networkSolve.js.
- The multiphase half is NOT in this engine. Two-phase pressure drop, flow regime and holdup are the Suite Beggs and Brill correlation, which is app code, and the engine takes the holdup as an INPUT wherever it needs one.
- A state the method has no answer for comes back as an object with an `error` string. This engine throws nothing: every refusal is a returned object, so a caller checks a property rather than catching.
- Liquid rates are taken at LINE conditions, the dead-liquid case downstream of separation. A live-oil flowline upstream of separation carries full PVT and belongs elsewhere.

States the method has no answer for, engine messages verbatim:
- a liquid line with no rate: { error: "liquid line drop needs positive rate, bore, length, density and viscosity" }
- a liquid line with a negative rate: { error: "liquid line drop needs positive rate, bore, length, density and viscosity" }
- a liquid line with no bore: { error: "liquid line drop needs positive rate, bore, length, density and viscosity" }
- a liquid line with no length: { error: "liquid line drop needs positive rate, bore, length, density and viscosity" }
- a liquid line with no viscosity: { error: "liquid line drop needs positive rate, bore, length, density and viscosity" }
- a traverse with no profile: { error: "a traverse needs at least one profile segment" }
- a gas line whose outlet meets its inlet: { error: "no flow: outlet pressure meets or exceeds inlet head" }
- an outlet-pressure solve on an unknown equation: { error: "unknown gas flow equation 'cylindrical'" }
- an outlet-pressure solve with no rate: { error: "outlet-pressure solve needs a positive rate" }
- an outlet-pressure solve the line cannot deliver: { error: "the line cannot carry the target rate even to atmospheric outlet" }
- a wall with no design pressure: { error: "wall thickness needs positive design pressure, OD and SMYS" }
- a wall to a code that does not exist: { error: "unknown design code 'B99'" }
- a wall to a B31.8 location class that does not exist: { error: "B31.8 has no location class 9" }
- a rating with no wall left after the allowance: { error: "no pressure-bearing wall left after corrosion allowance" }
- a sweep with a holdup above one: { error: "holdup must be between 0 and 1" }
- a pig that does not move: { error: "a pig run needs a positive length and speed" }
- an interval with no dropout: { error: "an interval needs a positive slug limit and dropout rate" }
- an interval whose sweep already overfills the catcher: { error: "the sweep alone already exceeds the slug limit: pig more often or resize the catcher" }
Those are states the METHOD has no answer for. Inputs that are not physically meaningful at all, a negative roughness or an efficiency above one or a corrosion allowance that removes metal, are refused as well, and the catalogue of them with the boundary either side is in Section 16.

# SECTION 7: A gas line is not a liquid line (owned by Professional m01)

The SOKU gas trunk as the studio reads it: 850.000000 psia at the station, 620.000000 psia at the delivery point, 11.938000 in of bore over 32.000000 miles, gas gravity 0.670000, average flowing temperature 535.000000 degR, average compressibility 0.885000, efficiency 1.000000.
The driving group is the difference of the SQUARES: 850.000000 squared less 620.000000 squared is 338100.0000 psia squared (derived, stated on the row). A liquid line subtracts pressures; a gas line subtracts their squares, because the density the friction sees is itself proportional to the pressure.
The base the published forms report at: 520.000000 degR and 14.650000 psia. A rate in scfd is a rate AT THAT BASE, so two forms quoted at different bases are not comparable even when they agree.
A line whose outlet meets its inlet has no answer at all: at 900.000000 psia out against 850.000000 psia in, the engine returns { error: "no flow: outlet pressure meets or exceeds inlet head" }.
A line that is nearly dead does have one: at 845.000000 psia out, five psi below the inlet, Weymouth gives 10466013.4729 scfd.

# SECTION 16: What it refuses, and what a refusal looks like (owned by Expert m04)

A refusal in this engine is an object carrying an `error` string. It is never a thrown exception, never a null and never a bare number, and the shape is the contract: a caller checks a property rather than inspecting a value. That is exactly why a NaN or an Infinity returned WITHOUT an error is worse than no guard at all. It passes the check and then propagates into whatever is downstream, which for this engine is a sizing sweep, a marched profile and a wall specification.
Three returns sit outside that contract on purpose. The Reynolds number and the line volume are bare numbers with nowhere to put a message, so they answer NaN by documented contract and the functions that wrap them refuse in words. The friction factor carries its refusal in the regime it already returns.
