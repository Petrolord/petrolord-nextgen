# Closed string and open

The single biggest choice in a trip.

{{panel:hy-surge-explorer}}

## The two numbers

Slant well, kcl_polymer, 0.5 m/s:

| string | pressure | surge EMW | swab EMW |
|---|---|---|---|
| closed | 981472.927055977 Pa | 1479.9065351493016 | 1400.0934648506984 |
| open | 837277.2706081835 Pa | 1474.0435623929657 | 1405.9564376070343 |

The closed string produces 1.172219719213269 times the pressure of the open one.

## What makes a string closed

**A float valve** in the bottom hole assembly, which stops flow back up the string.

**A plugged bit**, whether by a nozzle blocked with junk or by the bit balling up.

**A casing float shoe**, which is a float valve by another name and is standard on almost every casing run.

**A packer or a plug** being run on the string.

## What makes it open

An ordinary drill string with no float, or one with a ported float that allows fill.

## The practical consequence

The worst surge case on a well is a casing run: a large-diameter closed string in a tight annulus, run by a crew whose speed is set by how fast they can make up joints.

That is why casing running speeds are computed rather than chosen, why differential fill floats exist, and why the shoe track is where losses most often happen.

## The horizontal well is worse again

Slant well, closed, 0.5 m/s: surge EMW 1479.9065351493016 kg/m3, an uplift of 39.90653514930159.

Horizontal well, same conditions: 1517.947250200656 kg/m3, an uplift of 77.94725020065607.

Nearly double, for the same reason the equivalent circulating density is worse there: the pressure is divided by TRUE VERTICAL depth, and a lateral adds annulus and no true vertical depth.

## The combination that is worst of all

A closed string, in a horizontal well, run fast, in a tight annulus, with a narrow pressure window.

Every one of those multiplies, and the combination is the case a surge calculation exists to catch.
