# Onward

The vessel is sized and the plot is judged, which leaves a set of questions this engine deliberately does not answer and a set of figures waiting on a literature check.

## What lives in another engine

This engine sizes a vessel. What actually leaves each stage of a separation train at a given pressure and temperature is a flash calculation, and it lives in the fluid engine rather than here. A sizing result says the drum is big enough for the stream to separate in it, and it never says what the oil and gas compositions at the outlets will be.

The slug volume is the same kind of boundary. It is not computed in the slug catcher tab. It comes from the line, where the pigging work produces it, and it arrives here as a number somebody else stands behind.

## The four held items

The K derating with its 0.120000 floor, the horizontal use of Souders-Brown as a droplet settling velocity, the API 521 radiation labels and the spacing table figures are all recorded rather than checked. Each one becomes an answer the day a source is read against it, and until then each is a limit to state.

The spacing table has a second problem worth naming: it has no entry for a flow meter, a skid, a pig launcher or a booster package, so a real plot returns unknown pairs and reports complete false almost every time. A site standard carrying those types is what closes it.

## What is worth re-running

Any carryunder verdict computed before the interface repair was measured against a chord-rule layer, so it answered a different question. Any preferred diameter taken from the retired sweep could be a vessel that was merely first in the list, or one that could not carry its gas. Any layout reported as passing with nothing checked was reporting an absence of evidence.

None of those needs new physics. They need the same cases run again through the repaired engine and the answers compared.

## The habit that carries

Read the status beside the number, and ask of every figure whether it was computed, copied or refused. A computed figure moves when its duty moves. A copied figure never moves. A refusal names the input it wants.

That one question separates the parts of a design package that will survive a review from the parts that were only ever a table somebody transcribed.
