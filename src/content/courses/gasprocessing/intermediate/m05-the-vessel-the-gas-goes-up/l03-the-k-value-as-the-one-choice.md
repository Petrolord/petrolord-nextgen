# The K value as the one choice

Everything else in the sizing describes the stream. The K value is the one design choice in the whole calculation, and it is the only place a reader's judgement enters the width of the vessel.

## What it does to the answer

| K, ft/s | allowed velocity, ft/s | diameter, ft |
| --- | --- | --- |
| 0.150000 | 0.659228 | 4.515105 |
| 0.200000 | 0.878970 | 3.910196 |
| 0.250000 | 1.098713 | 3.497385 |
| 0.300000 | 1.318455 | 3.192661 |
| 0.350000 | 1.538198 | 2.955830 |
| 0.400000 | 1.757940 | 2.764926 |

Read down the two result columns of that table. The allowed velocity rises across those six rows and the diameter falls, on one stream, at one pressure and one temperature, with only the K value moved. That is what a clean single-variable sweep looks like, and it is the only one in this module where a reader can be certain nothing else moved with it.

## Where a K value comes from

Not from here. The K value is a chart figure, and the Separation and Slug Catching course owns the six published rows and the mist extractor arrangement that sets them. This module takes it as an input with a customary default and never derives one.

That is the right division. A K value encodes a mist extractor, an operating philosophy and a tolerance for entrainment, and none of those is visible to an engine that has been handed a rate, a pressure and a gravity. It is a choice, so it stays a choice, and it is on the page rather than hidden in the arithmetic.

## What a diameter therefore means

A diameter from this module is conditional on a K value in exactly the way a stage count is conditional on an absorption factor. Quote the one without the other and you have quoted a number that cannot be checked or reproduced.

The two teaching columns of this course make the point. OBIAFU is sized at a K of 0.300000 and UBIE at 0.250000, and the difference between the two diameters is not only a difference of stream. Anybody comparing them has to carry both K values alongside.

## A rule that travels

This is the third time in the tier that the same shape has appeared. A staged column has a factor somebody chose. A sweetening loop has a swing and a strength somebody chose. A contactor has a K value somebody chose. In each case the engine computes everything downstream of the choice faithfully and has no opinion at all about the choice itself.

So the reading discipline is always the same. Find the chosen inputs first, write them down beside the answer, and only then read the result. An answer separated from the choices behind it is a number without a question.

The module makes that easy on purpose. Every choice is an input on the page with its customary value named, rather than a constant somewhere in the source, and the answers report back which of those values they used.
