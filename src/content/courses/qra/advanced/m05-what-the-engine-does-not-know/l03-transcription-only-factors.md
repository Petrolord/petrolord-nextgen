# Factors resting on one reading

{{panel:qr-societal}}

Some numbers in the engine are published values it transcribed once. Nothing in the engine's validation checks them against a second reading, because the source prints no worked example that would. The engine still uses them, and this course still teaches them. Every capstone STATES them instead of asking for a lookup, and no graded answer ever passes through one. This lesson lists them, and adds the one calculation that is checked only against itself.

## The ignition table and the split

Purple Book Table 4.5 gives the probability of direct ignition for stationary installations by substance class and release size. For a continuous release of 50 kg/s the engine returns:

| substance class | direct ignition probability |
| --- | --- |
| k1-liquid | 0.065 |
| gas-low-reactivity | 0.04 |
| gas-average-high-reactivity | 0.5 |

The preset vapour cloud split, flash fire 0.6 and explosion 0.4, comes from Purple Book section 4.8. The table cells and the split are transcriptions of one source, read once. The engine's validation record labels the band-edge cells as its own reading and the interior cells as published.

## The fractions indoors and outdoors

For societal risk the Purple Book counts deaths indoors and outdoors separately. The factors 0.1 (toxic indoors), 0.14 (fire outdoors) and 0.025 (explosion indoors), and the Table 5.3 fractions, day 0.93 and night 0.99, are single transcriptions of the Purple Book, which prints no numeric example for them. The engine's own validation planted a wrong clothing factor in both the engine and its oracle, and the suite stayed green. A factor copied the same wrong way into both sides of a check passes that check, which is exactly why these factors are taught and never graded.

## The F-N curve, checked by itself

No published worked F-N curve was available, and the CCPS and HSE worked examples were not to hand. The curve is checked by SELF-CONSISTENCY ONLY: a brute force count at every corner, a second route on a grid of N, and the area identity. For the JISIKE off-site set the area under the step curve, 0.000336000000 per year, equals the expected fatalities per year, 0.000336000000. That identity shows the bookkeeping is consistent with itself. It cannot show that a published example would agree, so this course never presents an F-N figure as published-verified. The criterion side is published and reproduced; the curve side is consistent.

## What the analyst does

For each of these values the analyst states the value used and its source, and says that it rests on one reading. That is a short sentence in a note, and it tells a reviewer where to look first if a result surprises them.

## Exercise

Take the Table 4.5 value of 0.04 for a continuous release of 50 kg/s of a low reactivity gas. Write the sentence an ALARP note should carry when it uses that value, stating its source and that it rests on a single transcription. Then take the area identity figure of 0.000336000000 per year and write one sentence saying what it proves about the F-N curve and what it leaves unproven.
