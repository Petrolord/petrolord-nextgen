# Sources and the dates they were read

{{panel:pr-envelope-calculator}}

A rule in a tender evaluation is only as good as the text it comes from, and texts change. So this course names every law, regulation and guidance with its edition or gazette date and the date it was read. Every text below was read on 2026-09-26. Only public texts are quoted, always with their citation, and every threshold the engine applies is cited to its section. A figure that could not be sourced is an input you state, and the engine holds no default for it.

## The engine cites in its own words

Every result the engine returns carries a basis naming the rule it applied and where the rule comes from. For the technical envelope the source reads:

> World Bank Procurement Regulations (7th ed.) para 6.29; Nigeria Public Procurement Act 2007 s.51(2)

For the evaluated cost it reads:

> World Bank Procurement Regulations (7th ed.) Annex X para 3.6; Nigeria Public Procurement Act 2007 s.31(14) and s.32(3); World Bank Procurement Regulations (7th ed.) para 5.70; Nigeria Public Procurement Act 2007 s.24(3) and s.33(1)

The envelope calculator prints the rule of each result in the engine's words beneath it. The citations above travel with the result the engine returns, and the course prints them beside the working so you can see where each step comes from.

## Two kinds of text you will not see quoted

Some texts are sold under licence. The materials tender's criteria name API 5CT, API 6D, API 10A and API 13A data sheets as the bidders' specification. Those are paid standards, so the course names them by number and never quotes them. Model contracts sold under licence, such as the AIPN model contracts, are taught by concept only.

## When a text leaves a gap

The texts do not settle everything. The Standard Procurement Document gives a rate for late completion without saying what price the rate multiplies. No text read states a tie-break. Where that happens, the engine makes a choice, states it in its basis and calls it an engine convention. The lessons name each convention when they meet it, so you can see where the law ends and a stated choice begins.
