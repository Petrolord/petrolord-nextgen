# What the weights rest on

{{panel:hy-heat-stress}}

The golden holds 0 published cases for `wbgtIndoorC` and 0 for `wbgtOutdoorC`, with 2 oracle-only cases each. Both doors are classed TRANSCRIPTION ONLY. The time weighted door `wbgtTwaC` holds 0 published cases and 1 oracle-only case, and it is classed ARITHMETIC BY DEFINITION. Every WBGT built from thermometer readings in this course, including 30.090000 C, 31.410000 C and 32.560000 C, is the NIOSH 2016-106 section 9.3.2 weighting, checked for transcription only.

## Two copies of one page

The engine holds the weights 0.7, 0.3, 0.2 and 0.1, and the independent oracle holds them too. Each was typed from the same page of NIOSH 2016-106. When the suite compares the engine against the oracle and the two agree, that agreement says the two files hold the same numbers. It says nothing about whether those numbers match the page.

The engine's provenance record states what happens when that is tested. Planting the same error in both the engine and the oracle left the suite green for the WBGT outdoor weights. That is the expected result and it is the reason for the class. A check that compares two copies of one reading cannot catch a misreading both copies share.

## What would move the class

A door moves up to PUBLISHED, REPRODUCED when a value a source prints is reproduced by the engine at the precision the source prints it. A printed worked example would do it: readings in, an index out, both on the page. Two people copying the weights wrongly would then disagree with that printed index. No such value is known for the WBGT forms, so the class stays where it is.

The unit-impulse measurement of the previous lesson but one is a third location. The generator types 0.700000000000 as a literal and the engine returns 0.700000000000 when asked, so an edit to one file alone would show. It is a pin against quiet change. It is still a copy of the same page, and it cannot tell anyone the page was read correctly.

## What the class means for a report

A WBGT built from thermometers is a legitimate screening figure. The weights are published and widely used. What the class records is the strength of the evidence inside this course: the arithmetic was checked, and the constants were copied. A report can use the figure and should say which form built it.

## What it means for grading

A graded answer that a shared misreading would still pass is graded on nothing. So no graded field in this course passes through a WBGT built from thermometer readings. The one-hour average of an instrument's readout carries no weights at all, and the scenario states the readout. That is why the average is graded and the weighted index is taught.
