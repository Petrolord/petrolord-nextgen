# The capstone brief

{{panel:farmout-earning-calculator}}

The Associate capstone asks the tier's one question: the deal and what it costs. It gives you a synthetic farm-out of its own, with its own parties, well and terms, and asks for six values the engine returns. Each value tests a module of this tier. This lesson says what the capstone asks, where each value comes from in the earning calculator, and how to rehearse on the Ekene Deep deal first.

## What the capstone gives you

The capstone card carries one case file. It states every term a figure depends on: the parties and their participating interests, the farmor and the farminee, the event's gross cost, share paid, participating interest earned and cap, the vesting rule and the events completed, and the cash bonus and past costs with the share reimbursed. The case file holds a block for each view of the course's calculators; paste the whole file into the earning calculator's box and its view reads the `earning` block.

## The six values

| value | what it tests | where to find it |
| --- | --- | --- |
| what the farminee pays for the well | the earning obligation | the "farminee pays" column of the event row |
| what the farmor pays for the well | the earning obligation | the "farmor pays" column of the same row |
| the promote ratio | the promote and its ratio | the "promote ratio" column |
| the carry | the carry inside a promote | the "carry" column, or the "Carry" tile |
| the consideration to the farmor | the cash bonus and the reimbursement | the "Consideration to the farmor" tile |
| the equivalent working interest | the equivalent working interest | the "Equivalent working interest" tile |

All six are reported to six decimals, as the panel prints them.

## Things to check before you copy a figure

Run the checklist of the last lesson on the case file first. Check that the participating interests sum to 100 and that the farmor and the farminee are the ones the card names. Read the cap state column and the first reason line, which state how the engine split the well. Read the events completed: a tile counts completed events only, so a total of 0.000000 may mean the event is not done. Add the three payments for the event and check that they make up the gross cost.

## How your answers are checked

Every graded value is a return value of the engine on the card's terms, so there is exactly one right answer. Enter each value as the panel prints it. If the view refuses the case file, a term has been changed or mistyped: read the field the refusal names, restore the card's term and run it again.

## Rehearse on the Ekene Deep deal

The Ekene figures are printed in this course, so it is a safe place to practise every step.

| step | Ekene figure |

| what EKO pays for the well | 14000000.000000 |
| the promote ratio | 1.333333 |

| the consideration to EKO | 10000000.000000 |

For the payments, check that FIN's 18200000.000000, EKO's 14000000.000000 and PA's 13800000.000000 make up the gross cost of 46000000.000000. For the consideration, check that the carry, the bonus of 2000000.000000 and the reimbursement of 3600000.000000 make up 10000000.000000.
