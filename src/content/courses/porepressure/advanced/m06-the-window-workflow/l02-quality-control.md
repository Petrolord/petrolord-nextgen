# Quality control

The Professional tier's QC list survives whole; this tier adds the checks its four new steps deserve. As before: each check with the number it produces on this well and the failure it exists to catch. The full list, old plus new, is the inspection pass for any window anyone hands you.

## Inherited checks, one line each

Frame checks, ordering checks, quiet-section check, slope check, consistency identities, loop closure, sensitivity declarations: all run upstream, all pass here, and any failure upstream invalidates everything below. A window built on an unchecked prognosis is decoration.

## The datum check

Every EMW in the document references the same stated datum. On this well: sea level, columns z plus 100 m. The two tests: the hydrostatic EMW must sit just BELOW the pore fluid density, 1029.878 against 1030 at TD, the Associate tier's own seawater-fraction signature; and a 25 m datum slip moves the TD floor by 7.15 kg/m3, fourteen tolerances, so any unexplained offset of that size between two documents is a datum suspect first. Failure caught: mixed references, the silent killer of multi-author well plans.

## The bracket check

Floor and ceiling must sit strictly inside the frame's EMW curves at every depth: here 1179.10 and 1903.92 inside 1029.88 and 2266.33 at TD, and likewise all the way up. A wall outside the bracket is an arithmetic error with no possible physical reading. Ten seconds on the panel plot: both curves inside the dashed pair everywhere. Failure caught: column slips, the divide-by-z-instead-of-z-plus-water class, which land 29.48 kg/m3 heavy at TD and clear the bracket only because the bracket is generous, hence the next check.

## The commutation check

Window arithmetic must agree along every route: subtract then convert, convert then subtract, or the K-algebra route, module 2 ran all three at TD and 3000 m with worst disagreement in the thirteenth digit. Failure caught: transcription between tables computed at different times, and any hidden re-rounding between report drafts.

## The shape re-read

Window shape is calibration-conditional: this well narrows below the onset at n 3, 750.28 to 724.82, and widens at n 1.2, 750.28 to 782.97. The check: after ANY recalibration, re-read where the section's narrowest point sits rather than assuming it survived. Failure caught: stale section logic, a shoe planned against a pinch that the refit moved.

## The cross-check residual audit

The Bowers comparison is only QC if its residual is understood: 0.038 MPa at TD here, traced to the 1.408 m/s fit residual through the 0.0269 MPa per m/s gain. The check is the TRACE, not the size: an unexplained small residual is luck until shown otherwise, and an explained moderate one can be fine. Alongside it, the mechanism screens: no reversal, no sonic-density split, documented. Failure caught: false comfort from agreement that two shared inputs manufactured, and mechanism misreads that both methods would make together.

## The margins ledger

Every margin named, sized and subtracted in the open: kick, trip, ECD, surge against this well's 601 kg/m3 of operational room. Failure caught: the double-spend, where the same window room is silently counted against two different margins by two different documents, discovered on this list rather than on the rig.

## What still cannot be caught

The honest tail, extended one method deeper: shared-input error now spans BOTH methods, a biased sonic or overburden moves Eaton and Bowers together, and the cross-check cannot see it. External data remains the only defence: measured pressures, leak-off tests, drilling response. The list's last line is therefore unchanged from the tier below, and permanent: know, for each check, what failure it cannot catch, and know which measurement would.

## Worked example

Audit a hostile document with the new checks. A contractor's window plot for this well shows floor 1208.6 and ceiling 1951.5 kg/m3 at TD, window 742.9. Bracket check: both inside the frame bracket, passes. Commutation: internally consistent, passes. Datum check: both values are exactly the divide-by-4000 versions of the true walls, module 1's trap two, the water column dropped from both columns. One check fires, the other two pass, which is the designed redundancy: the window width is nearly right, 742.9 against 724.8, because the error partially cancels in the subtraction, so a width-only review would have approved it. Walls first, width second, always.

## Exercise

Construct the opposite trap: an error the width catches but the walls nearly hide, and name the check that formalises it.

Self check: swap one wall's calibration, floor from the n 1.2 run at 1091.88 beside the ceiling from the n 3 run at 1903.92: both walls individually plausible, both inside the bracket, but the width reads 812.04, wider than either calibration's true window, 724.82 or 782.97. The commutation check formalises the catch: the K-algebra route, two thirds of overburden-minus-floor, predicts 782.97 for that floor, not 812.04, and the mismatch exposes the mixed provenance. Widths and walls must reconcile through the algebra, which is why the course kept drilling all three routes.
