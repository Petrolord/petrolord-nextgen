# The four kinds of number in this module

Every number a reader meets in this engine belongs to one of four kinds, and being able to place a figure in the right one is the single most useful habit this course can leave behind. Every number that is a choice rather than a derivation lives in one frozen object called DECLARED_CONSTANTS, and the engine reads each one from there rather than writing it into the line that uses it.

## Derived, which means there is nothing to check

A derived number follows from something else on the page, so there is nothing to validate and nothing to argue about. The grade efficiency of any device at its own cut size is exactly one half, 0.500000000000, because that is what a cut size means. Standard gravity can be measured back out of the engine from its own reported rise velocity, and it comes to 9.806650 m/s2, which is a property of the planet rather than a choice anybody made. The natural logarithm of two, 0.693147180560, falls out of a capture law the same way, because a cut size is the size at which half the volume goes and half survives.

## Declared, which means somebody chose it

A declared number is customary or chosen, and this repository carries no publication to check it against. The engine's own comment says that pinning such a value is all any gate can do. A pin is not a validation. What a pin buys is that moving the number becomes a reviewed act instead of a silent one. A handful of them, out of a frozen export carrying 55 keys in all:

| declared constant | value | what it sets |
| --- | --- | --- |
| salinityViscosityMultiplier | 1.8 | how fast viscosity rises with dissolved solids |
| brineDensitySlopeKgM3 | 700 | how fast density rises with dissolved solids |
| defaultNBins | 60 | the droplet grid, bin count |
| defaultSharpness | 3 | the grade curve of the gravity and centrifugal devices |
| shortCircuitFDefault | 1.5 | the API 421 turbulence and short-circuiting allowance |
| plateEfficiencyFactor | 0.7 | the fraction of a plate pack projected area that settles |

## A calibration, and there is exactly one

One number in this module has no derivation at all. The attachment efficiency is 0.01, the probability that a droplet colliding with a bubble sticks, and it was chosen so that a cell at the module's own default conditions lands in the range flotation is customarily credited with. It is an input, so an engineer holding a vendor curve can move it. Nothing in this course presents it as published, and no graded answer anywhere in this course depends on it.

## Held for literature, which means the module says so

Six numbers or rules are simply absent from this repository, and the module states the absence rather than guessing. The value of the dissolved and soluble oil floor is one. The second half of the API 421 horizontal velocity rule is another. Any discharge limit at all is a third, and a test asserts the declared constants carry no specification-like key. Stating an absence is the honest form and it is also the harder one to write, because a number invented to fill a hole looks exactly like a number that was measured.

## Exercise

Take three figures from later in this course and place each one in its kind, saying what evidence would settle each placement. Then say what would have to appear in this repository before 0.01 could move from the third kind to the first.
