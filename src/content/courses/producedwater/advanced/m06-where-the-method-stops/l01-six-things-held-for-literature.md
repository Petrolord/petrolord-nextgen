# Six things held for literature

Held means this repository carries no publication for the number, so the module states the ABSENCE rather than guessing, and no gate pretends to validate it. A reader who can list these six has the most useful map of the module there is.

## One: the dissolved and soluble oil floor

No device here removes dissolved oil, so there is a floor under every outlet this train reports, and its value is not in this module. The existence is stated on every train return. The value is the caller's, and when a caller supplies one the engine reports the dispersed figure and the floored figure side by side so a reader can see which is which.

## Two: the second half of the API 421 horizontal velocity rule

The standard limits the horizontal velocity to the LESSER of a fixed velocity and a multiple of the design droplet rise velocity. Only the fixed half is here, and every return carrying the check also carries `velocityRuleComplete` false.

So a basin that passes this check has passed half a rule. The OGBOTOBO basin runs at 0.013591874698 m per second against the 0.015000 m per second fixed limit with no warning, and that result is worth exactly half of what it looks like.

## Three: any discharge limit at all

This module states none, and a test asserts that its declared constants carry no specification-like key. A specification is something the caller supplies out of their own permit or regulation. The module compares, reports a margin, and withholds the comparison when there is nothing to compare against.

## Four: the media filter grain size exponent

The interception derivation gives the inverse CUBE of the grain size, and the input moves the answer by a large factor. No bed data in this repository can check that exponent. Treat the grain size column as the model's statement rather than as a measurement.

## Five: the attachment efficiency

The one calibration in this module, and the subject of the next lesson. It is held AND it is a calibration, which is a combination worth noticing.

## Six: the device shape and scale constants, one at a time

Sharpness three, the plate pack efficiency factor, the whole liner geometry with its rated field and design flow, the flotation interception coefficient, the filter reference triple and the customary bands. Pinned by literal, never validated.

## One more statement, which is not a number

The hydrocyclone capture this model computes is an IDEAL. Re-entrainment, the reject split and the shear the liner itself applies are not in it, and field de-oilers are customarily credited with a coarser cut than this model gives. No vendor performance curve exists in this repository to calibrate against. That is a statement about what the model leaves out rather than a number, and it belongs beside every cyclone cut size this course prints.

## Exercise

For each of the six, write the sentence you would put in a report when quoting a figure that depends on it.

Then decide which of the six you would fund a measurement for first, and say what that measurement would have to produce to be worth anything.
