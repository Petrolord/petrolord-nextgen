# What is held and what is decided

Every engine carries decisions and limits. This course separates them. Four items are held: stated as limits, taught and never graded. The rest are rules in force, and each prints somewhere in this course with a figure. This lesson reads both lists, with the Expert tier's rules in detail.

## The held items

| item | the limit |
| --- | --- |
| H1 | Which IPCC assessment report a Nigerian operator files on (AR5 or AR6) is a regulatory reading and the owner's decision. The engine ships no GWP; the course prints both reports (Associate module four). |
| H2 | The engine's typical methane heating values are 802.6 LHV and 890.8 HHV MJ per kmol, a difference of 88.2 (computed here); two moles of water condensed at the engine's own latent heat is 87.985 MJ (computed here: 2 x 18.015 kg, the H2O of energyEfficiency.PRODUCT_MOLAR_MASS (Associate module one), x 2442 kJ/kg). The pair is labelled typical and is not corrected without ISO 6976 in hand; the fuel analysis governs. |
| H3 | Every escaped carbon atom is counted as methane (Associate module three). |
| H4 | Combustion N2O is not computed by the atom balance; it needs an emission factor line (Associate module two). |
| inputs | GWP values, emission factors and every price are inputs. Neither engine ships one. |

Each held item is a limit a reader states. H1 is not answered here: this course computes every inventory on IPCC AR6 GWP100, fossil methane, prints the other sets beside it, and names no report an operator should file on. H2's two figures, 88.2 and 87.985, are both marked computed here and are not engine outputs. H3 is, in the Associate tier's words, "the engine's stated and conservative assumption". H4 names a gas the atom balance does not count.

The inputs row is the one this tier leans on most. Every cost, saving, rate, life and tonne on the Agbor measures is an input the user types. The engine prices what it is given.

## The held items on the Agbor records

Two of the held items reach the Agbor inventory this tier's curve and path are built on. The flare source passed to the curve, 7562.133 tCO2e, is the Flaring (CO2) line of 6189.848 tCO2e and the Flaring (unburned CH4) line of 1372.285 tCO2e (module three). The methane line exists because of H3: every escaped carbon atom is counted as methane, and it is converted to CO2e on IPCC AR6 GWP100, fossil methane. The Agbor inventory table in module three prints five lines, and none of them is a nitrous oxide line. H4 says why a combustion N2O figure would need a line of its own with an emission factor.

H1 reaches every figure in tCO2e. The Agbor baseline of 56100.276 tCO2e is on the course's set. The Associate tier prints the Igbogene inventory on all four sets and shows that only the methane lines move. The Agbor inventory is printed on one set only, and this course prints no other total for it.

## The rules in force for this tier

| rule | where it prints |
| --- | --- |
| A negative abatement, a blank capital cost, a blank rate with capital, and a rate outside (-1, 1) are refused; blank savings and running costs are 0 and named | module one |
| A curve with a claim above what its source emits returns meetsTarget none and says why | module three |
| A baseline that is not positive is refused, and a measure with no start year is named | module four |
| The cost per tonne of a saving is the levelised abatementCost, and needs a life and a rate | module five |
| An intensity with a stream missing is not compared with the peer | module five |
| A saving, its price and its factor declared on different heating value bases are refused | module five |
| A curve verdict is none while any claim acts on a source with no computed emission passed, and the basis names the sources | module three |
| A refused measure is named in refusedMeasures and kept off the curve | module one |
| A year whose scheduled measures abate more than the baseline is refused | module four |

The last three are from the course's table of the rules MD45-1 put in force.

## What the rules share

Each rule treats a missing or impossible input as missing. A blank capital is refused because a blank is not read as free. A blank rate is refused because reading it as 0 would move the measure down the curve. A claim above a source's emission gives no verdict, and so does a claim on a source with no emission passed. A stream left out withholds the peer comparison. A saving with no life and no rate returns no cost per tonne and says why. Where the engine does fill a box, as with blank savings and running costs, it names what it filled.

## What this tier decides and what it does not

This tier reads the rules and quotes the refusals. It does not decide a discount rate, a GWP set, a target percentage or a start year: every one is an input. The engine gives no target verdict on a curve carrying a claim it could not check against its source, and this tier reads none from it.
