# Which set to file on

## A question the course does not answer

An operator who has built an inventory on a declared GWP set will be asked which set to file it on. This course does not answer that question. It is a held item, and this lesson teaches it as a stated limit.

The digest states the limit in full:

"HELD, FINDINGS-carbon H1: which assessment report an operator should file on. AR5 is what UNFCCC reporting has required and AR6 is what the GHG Protocol now recommends; which one a Nigerian operator files on is a regulatory reading, and a recommended default is the owner's decision. The course teaches both sets and grades no choice between them."

## Reading the limit

The limit has four parts, and each is a statement the digest prints.

First, the digest names where each report stands: AR5 is what UNFCCC reporting has required and AR6 is what the GHG Protocol now recommends.

Second, which of them a Nigerian operator files on is a regulatory reading.

Third, a recommended default is the owner's decision. The engine ships no GWP at all, and the course recommends none.

Fourth, the course teaches both sets and grades no choice between them.

The held items table in the digest restates it in one row: "Which IPCC assessment report a Nigerian operator files on (AR5 or AR6) is a regulatory reading and the owner's decision. The engine ships no GWP; the course prints both reports."

## The course's set is a computing choice

The course computes every inventory on "IPCC AR6 GWP100, fossil methane". That choice has a stated reason, the engine's methane note: the atom balance counts escaped carbon as methane, so the fossil value is the consistent one. The reason is about how the engine counts carbon. It says nothing about which report a regulator requires, and it is not advice on what to file.

## What the choice would move at Igbogene

The digest prints what the report changes, and it is worth knowing before anyone decides. On the two fossil sets, the Igbogene total is 42945.777 tCO2e on AR6 and 42977.438 tCO2e on AR5, and the digest prints the AR5 total less the course set as 31.661 tCO2e. Each is computed on its own set. The filing decision picks which one is reported.

In practice, a regulator's reporting instructions name the edition of the GWP values they require, and that instruction is the document the choice should cite.

Whichever set is chosen, the engine states it on every result as gwpSetLabel, so the result carries the set it was converted on.
