# The capstone brief

{{panel:prms-aggregation-calculator}}

The Expert capstone asks the tier's one question: aggregation, reconciliation and the limits. It gives you a synthetic field of its own, with its own projects, distributions, chances and movements, and asks for six values the engine returns. It is worked in the course's own aggregation calculator, which calls the same vendored engine every lesson has quoted. There is no Suite app for this course: the calculator is the practical.

## What the capstone gives you

The capstone card carries one case file with three calls in it, each under a block key: a Reserves aggregation under `aggregate:reserves`, a Contingent Resources aggregation under `aggregate:contingent`, and a reconciliation under `reconcile`. Each call states every input its figures depend on: the class, the level, the unit, each project's distribution and chance, the correlation, the seed and the draws; the opening, the movements, the stated closing and the tolerance. Paste the whole file into the box of the view you need and choose the call in the block selector.

## The six values

| value | what it tests | view and where to read it |
| --- | --- | --- |
| the arithmetic 1P of the Reserves | summing by category | the aggregation view, the arithmetic table |
| the arithmetic 3P of the Reserves | the same sums | the aggregation view, the arithmetic table |
| the risked mean of the Contingent Resources | the risked mean | the aggregation view, the Risked mean tile |
| the computed closing 1P of the reconciliation | opening, movements and closing | the reconciliation view, the closing table |
| the computed closing 3P of the reconciliation | the same | the reconciliation view, the closing table |
| the difference at 2P of the reconciliation | a reconciliation that does not close | the reconciliation view, the difference column |

All six are reported to six decimals, as the panel prints them. None is a Monte Carlo draw, and none depends on a reading the engine states: each is the same number under every reading and under the alternative named beside it. The sampled P90, P50 and P10 on the card's seed are there to read and are not graded.

## Things to check before you copy a figure

Check the block selector shows the call you mean. Read the Class and Level controls of each aggregation. For the arithmetic figures, read the arithmetic table. The Monte Carlo table beside it prints the sampled P90, P50 and P10, which are estimates. For the risked mean, read the tile; the sum of the means is the unrisked figure beside it. For the reconciliation, read the computed closing, which is the engine's sum, and the difference, with its sign as printed.

## How your answers are checked

Every graded value is a return value of the engine on the card's inputs, so there is exactly one right answer. Each is compared with the engine's own return within a tolerance set once for the whole course. Enter each figure as the panel prints it, with no rounding of your own. If the view refuses the case file, an input has been changed: read the field the refusal names, restore the card's input and run it again.
