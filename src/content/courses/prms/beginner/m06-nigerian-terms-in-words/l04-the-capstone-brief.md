# The capstone brief

{{panel:prms-classification-calculator}}

The Associate capstone asks the tier's one question: classes, categories and the low estimate. It gives you a synthetic licence of its own, with its own prospect, lead and category sets, and asks for six values the engine returns. This lesson says what the capstone asks, where each value comes from in the classification calculator, and how to rehearse on the Ekene field first.

## What the capstone gives you

The capstone card carries one case file with four calls in it, each under a block key: a prospect and a lead under `classify:` keys, and a Reserves set and a Contingent Resources set under `categorize:` keys. Each call states every input its figure depends on: the discovery status, the recovery project, the sub-class and the two chances for the prospect and the lead; the class, the method, the unit and the estimates for each category set. Paste the whole file into the box of the view you need and choose the call in the block selector.

## The six values

| value | what it tests | view and where to read it |
| --- | --- | --- |
| the prospect's chance of commerciality, percent | the chance of commerciality | the class view, the Chance of commerciality tile |
| the lead's chance of commerciality, percent | the chance of commerciality | the class view, the same tile |
| the Probable (P2) of the Reserves | the proved, probable and possible slices | the categories view, the increments table |
| the Possible (P3) of the Reserves | the same slices | the categories view, the increments table |
| the 2C of the Contingent Resources | the categories of the other classes | the categories view, the cumulative table |
| the 3C of the Contingent Resources | the same categories | the categories view, the cumulative table |

All six are reported to six decimals, as the panel prints them.

## Things to check before you copy a figure

Check the block selector shows the call you mean; a prospect and a lead sit side by side in one file. Read the Class tile: both undiscovered projects should come back as Prospective Resources. Read the Method tile of each category set: the Reserves and the Contingent Resources sets may be stated in different forms, and the engine returns both forms whichever was stated. For a slice, read the increments table; for a C category, read the cumulative table. Check the probability labels run P90, P50, P10 from low to high.

## How your answers are checked

Every graded value is a return value of the engine on the card's inputs, so there is exactly one right answer, and no value depends on a Monte Carlo draw. Enter each as the panel prints it. If the view refuses the case file, an input has been changed or mistyped: read the field the refusal names, restore the card's input and run it again.

## Rehearse on the Ekene field

The Ekene figures are printed in this course, so it is a safe place to practise each step.

| step | Ekene figure |
| --- | --- |
| the chance of commerciality of Ekene Deep, the prospect | 20.000000 |
| the chance of commerciality of Ekene Shallow, the lead | 10.500000 |
| the Probable (P2) of the Ekene Main Reserves | 7.760000 |
| the Possible (P3) of the Ekene Main Reserves | 8.340000 |
| the 2C of Ekene North | 4.500000 |
| the 3C of Ekene North | 6.500000 |

For the chances, check each against the product of the two stated chances. For the slices, check each against the difference of two cumulative figures. For the C categories, check the 3C against the sum of the three slices.
