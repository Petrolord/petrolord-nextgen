# What a fitted factor absorbs

Five errors that all come out as the same number.

## The list

**A survey that does not describe the hole.** Real holes spiral, have micro-doglegs between stations, and are rarely circular. The survey gives smooth arcs. The extra tortuosity is real contact force the model does not see, and it lands in the factor.

Some software adds a "tortuosity" term to the survey explicitly for this reason, which is an admission that the factor was carrying it.

**A string description with the wrong contact diameter.** Tool joints missing, stabilisers not modelled, a jar or a reamer left out. Each one changes both the contact radius and the local clearance.

**A wrong mud weight.** Buoyancy scales the whole weight of the string. An error of 60 kg/m3 in the mud is about 0.8 percent of the buoyed weight, which on a 1000 kN hookload is 8 kN, which is a fitted-factor shift of about 0.01.

**Hole cleaning.** Cuttings beds are not friction and they present as friction. This is the one people most want the factor to carry, and it is the one that changes fastest.

**The model's own omissions.** Bending stiffness, dynamics, static versus kinetic friction, hydraulics. All of it, permanently, in every fit.

## Which of them you can separate

The mud weight, easily: it is measured at the shakers every tour and it should be in the model as measured rather than as planned.

The string description, easily: it is a bill of materials and it should be right.

The survey, partly: comparing a fit in a cased section, where the geometry is known and the surface is smooth, against a fit in open hole isolates some of it.

Hole cleaning, by its time behaviour: it changes over hours while the geometry does not.

The model's omissions, not at all. They are a permanent offset in every fitted factor, which is why factors fitted with one software package are not comparable with factors fitted using another.

## The consequence for reporting

A fitted friction factor should be reported with the model, the software, the survey, the string description and the date.

That is the same list the Well Design and Surveys course requires alongside an uncertainty ellipse, and for the same reason: a fitted parameter is only meaningful with the fit that produced it.

## The consequence for planning

A factor fitted on the last well in the field is the best available number for the next one, and it is only transferable if the two wells are drilled with the same model, the same software and a similar geometry.

Book values are for when there is no fitted value. A fitted value from an offset well beats a book value, and a fitted value from THIS well beats both.
