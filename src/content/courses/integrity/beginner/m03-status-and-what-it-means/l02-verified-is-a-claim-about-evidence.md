# Verified is a claim about evidence

Verified means somebody tested it and the test is still current. It does not mean it looks fine.

{{panel:wi-envelope-explorer}}

## What the word is doing

The engine's own label for the check spells out the standard it is holding you to:

`Every element verified (initial + periodic test)`

Two words in that label carry the weight. **Initial**, so the element was demonstrated to work when it was installed. **Periodic**, so it has been demonstrated again since, on whatever interval the element's type and the well's category require.

Verified is therefore a statement about a document, not about a component. You are not claiming the packer is good. You are claiming there is a test result that says so and that the result has not aged out.

## The two ways an element stops being verified

An element leaves the verified column for one of two reasons, and they are completely different.

The **test failed or degraded**. New evidence arrived and it was bad. The element moves to degraded or failed.

The **test expired**. No new evidence arrived at all. The element moves to not-verified. Nothing physical happened. The clock ran out.

The second one catches people, because nothing about the well changed on the day the status flipped. What changed is that the claim you were making stopped being supportable.

## In the published roster

The worked case carries 10 elements. Nine of them are verified and one, the DHSV, is degraded. The `all-verified` check passes on this roster, because that check asks only whether any element is sitting at not-verified, and none is. A degraded element has evidence. It has bad evidence.

Re-rate that same DHSV to not-verified and the `all-verified` check starts failing, listing the element by name. Same well, same hardware, different claim.

## What this costs you

Every verified status on a barrier table is a promise you can be asked to produce paper for. If you cannot produce it, the honest entry is not-verified, and the next lesson shows exactly what that costs.
