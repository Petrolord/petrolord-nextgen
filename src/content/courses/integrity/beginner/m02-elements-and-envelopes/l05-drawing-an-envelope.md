# Drawing an envelope

The engine checks your list. It does not check your drawing, and this lesson is about the part that is still yours.

{{panel:wi-envelope-explorer}}

## Start at the source and work outward

An envelope is a closed surface around a pressure source. You cannot draw it by listing equipment you happen to trust. You draw it by starting at the fluid and following every path it could take.

Begin at the reservoir. Ask what stops the fluid moving sideways into the rock behind the casing, then what stops it entering the wellbore, then what stops it travelling up the wellbore, then what stops it leaving at surface. At every step there must be an element, and the elements must join.

Trace the published primary envelope that way. The cement across the production interval closes the annular path behind the pipe. The casing below the packer closes the wall. The packer closes the gap between casing and tubing. The completion string carries the fluid upward inside a pressure-tight tube. The safety valve closes that tube. Five elements, and they meet each other with no gap between them.

Now trace the secondary. The intermediate cement, the production casing, the wellhead, the tubing hanger and the Christmas tree. The same journey by the outside route, and the same requirement to join.

## What a complete envelope has to reach

An envelope that stops halfway is not a small problem. It is not an envelope.

It has to enclose the source on every side, including behind the casing, which is where cement is doing work you cannot see. It has to run continuously, with each element sealing to the next. And it has to terminate in something that can be closed, at surface or at the mudline, because containment that ends in an open pipe is not containment.

Whether your envelope satisfies any of that is the engineer's drawing. The engine states plainly that geometric closure is not something it verifies.

## The gap this leaves, and how to cover it

Take that seriously, because the failure mode is quiet. Give the engine three verified elements that do not join into anything, and the rollup returns intact. Give it three verified elements that leave the annulus wide open, and the rollup still returns intact. Every element you listed passed, so the envelope passes.

The engine catches the empty envelope, which rolls up as empty and drops a flowing well to orange. It cannot catch the envelope that is populated but not closed.

So the drawing comes first and the table second. Sketch the well, mark the source, draw the two loops, and only then write the element list from what your pencil crossed. A table built from a drawing can be trusted. A drawing reconstructed from a table usually cannot.

## Exercise

Sketch the published well and draw both envelopes as closed loops around the reservoir. Mark on the sketch where each of the ten elements sits.

Then remove one element from your sketch, any one, and say in a sentence what path the fluid now takes. Check whether the engine's rollup would have noticed.
