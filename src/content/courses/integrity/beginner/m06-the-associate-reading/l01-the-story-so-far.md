# The story so far

Five modules, and every one of them was about evidence.

## The single idea

An element status is not a description of steel. It is a claim about what somebody has demonstrated, and when. Verified means there is a test result on file that is still in date. Degraded means somebody looked and found the element impaired. Failed means somebody looked and found it not containing. Not verified means nobody can currently show you anything, which is why it degrades an envelope exactly as an observed impairment does.

Once you read the statuses that way, the rest of the tier is one sentence. The envelope verdict is the weakest claim in the envelope, and the category is what that weakest claim obliges you to do.

## How the modules built it

Module one set the frame. Integrity is containment, a well that can flow to surface needs two independent envelopes, and the engine is honest about what it does not model: it rolls up statuses and checks the rules, and leaves geometric closure to your drawing.

Module two gave you the pieces. Elements of fourteen kinds, sorted into a primary envelope and a secondary one, with the common element that sits in both, which is a well that has lost independence without losing any element at all.

Module three was the vocabulary of evidence itself: four element statuses, verified as a claim rather than a condition, and not verified degrading an envelope exactly as degraded does.

Module four turned claims into verdicts. The worst element sets the whole envelope, and the vocabulary changes as it does, from verified and not verified to intact and empty. A shared element can degrade both envelopes at once, and the seat count exceeds the physical element count by exactly the number of shared elements.

Module five turned the verdicts into an instruction. Two verdicts in, one colour out, and each colour is a defined obligation rather than a score.

## Where the chain nearly broke

The category function used to accept any string and fall through to green for anything it did not recognise. Hand it the element status not verified and it answered green for a well whose primary envelope nobody had checked. Its sibling already refused unknown element statuses, so two halves of one boundary disagreed about whether to trust their caller, and the trusting half failed in the one direction an integrity function must never fail in. Both refuse now.
