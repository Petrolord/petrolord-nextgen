# One element sets the whole

An envelope is a chain, and its verdict is not an average of its links.

{{panel:wi-envelope-explorer}}

## The chain

An envelope is a set of elements that together enclose the flow source. Pressure that wants to reach surface has to get past all of them. It only has to get past one of them to be somewhere it should not be.

That geometry is why the verdict cannot be a score. A chain with nine sound links and one broken link is a broken chain. It is not ninety percent of a chain.

## What the engine actually does

The rollup takes an envelope's elements and returns one word for the whole envelope. It does not count how many are verified. It does not weight them by importance or by size. It looks for the worst status present and reports the consequence of that one.

There is no input to the rollup for element importance, and that omission is deliberate. Every element in an envelope is load bearing, because if it were not, it would not be in the envelope.

## The published roster

The worked case has 5 elements in the primary envelope. Four are verified: the production casing cement, the production casing below the packer, the production packer and the completion string. The fifth, the DHSV, is degraded.

The primary envelope reads **degraded**.

Not "mostly intact". Not "degraded in one place". The envelope, as a whole, is the thing that has been downgraded, because the envelope as a whole is the thing you were going to rely on.

The secondary envelope on the same well has 5 elements and all of them are verified, so it reads **intact**. Two envelopes, the same number of elements each, and one bad element between them decides which is which.

## Why this feels harsh and is not

The instinct against it is that a single leaking valve seems like a small thing next to four sound elements. It is a small thing. It is also the only thing standing between the reservoir and the next element out, at the place where the valve sits.

Averaging would let you buy that valve's weakness with other elements' strength, and those other elements are not in a position to help. They are somewhere else in the chain.
