# What the next tier changes

This tier has read one month's plan and the schedule it cascades into. The course's one sentence has four parts: the screen prices the barrel before any capital is spent, the plan finds it with every barrel run through the crude unit, the schedule dates it, and the actuals are read against it line by line on what each gap did to margin. This tier taught the second and the third. The Expert tier teaches the fourth, and returns to capital.

## What stays the same

The plan stays. The Expert tier works with a plan of the same kind: crudes, units, products and streams, a feedless crude unit carrying every barrel, a margin of revenue less crude and unit operating cost, and a gross margin per barrel of crude. What this tier said about blanks, refusals and stream values still holds.

The schedule stays too. Its shape, spread evenly across a period and dated from a fixed period start passed as a string, is the object the Expert tier reads actuals against. The engine's note says so in its own words: "this is the shape of the month to read actuals against. Berth-level scheduling needs those constraints and a scheduling tool."

## What changes

**A month that has happened.** This tier read a plan, which is what the month should do. The Expert tier reads actuals, which is what it did. The same event shape carries both. Setting one beside the other gives a gap on every line.

**Gaps read on margin.** A gap in a quantity or a price is a number. The question the Expert tier asks of each is what it did to the month's margin.

**Units against plan.** This tier read utilisation as the plan's output. The Expert tier reads each unit's actual run against what the plan asked of it.

**Capital again.** This tier's debottleneck sweep priced a barrel of capacity for one month and stopped there. The Expert tier values an expansion: an expansion's streams run through the screening engine, with tax losses carried forward. The feasibility answer it prints is the screen's answer, and the Economics courses own how such answers are built and judged.

## What to carry forward

Three habits from this tier matter most in the next.

Read the configuration before the numbers. A blank that should have been a zero, or a crude unit given a feed, changes every figure after it, and an actual read against a wrong plan is a gap the refinery did not have.

Read margin, and read it per barrel of crude, because the Expert tier reads every gap on margin.

Pass the period start, as a string. A schedule that moves with the clock or the time zone cannot be read against anything, and the next tier reads everything against it.
