# A golden file declared synthetic

The published case file for this module carries 19 sections and 75 rows, and it opens by declaring itself synthetic. No row in it is taken from a publication, because this repository holds no published heat exchanger case to take one from. Saying so is the honest option, and the alternative would have been to invent a citation that readers could not check.

## What a golden figure actually is

A golden figure is not the engine answering. The file is written by an oracle, which reaches every value by a different route from the one the engine takes. So a golden column standing beside an engine column is two methods meeting, to as many digits as the two of them agree to, and that is the only reason the column is worth printing.

Read the route before the number. For the log mean the oracle integrates the driving force and never evaluates a logarithm. For the coefficient it builds each resistance on its own area and refers the stack to the outside tube surface only at the end, taking the wall term by quadrature. For the bundle it bisects on the diameter. For the hot day it bisects the surface equation and never touches the effectiveness relation.

## What stands in for publication

Three things, and the module names all three. Route independence, which is the paragraph above. The constant pins, which make a change to a fitted number a reviewed act rather than a silent one. And the analytic limits, which are known truths that a wrong implementation cannot satisfy by accident.

The three are not interchangeable. An independent route catches a wrong implementation of a form both files agree about. A pin catches a change nobody meant to make. A limit catches a wrong form, including one that both files hold. Any figure in the file rests on at least one of them, and a reader is entitled to ask which.

| analytic limit | what it fixes |
| --- | --- |
| a thin cylindrical wall is a flat plate | the factor of two in the wall term, which no transcription check can fix |
| the parallel ceiling and the 1-2 shell ceiling | the two closed forms at high NTU |
| every arrangement collapses at a capacity ratio of zero | three separate branches against one another |
| counter-current flow has no ceiling | the claim that every arrangement has one |
| self-consistency across the whole chain | a duty and a surface that do not satisfy their own equation |

## What the declaration costs and what it buys

It costs the comfort of a citation. A reviewer who wants a page number does not get one, and a course written from this file has to say so in front of learners rather than quietly.

What it buys is a file whose weaknesses are written on its face. A reader knows which figures rest on an independent route, which rest on a limit, and which rest on a pin that nothing has validated. A file that claimed a source it did not have would read as stronger and would be weaker, because the one thing nobody could check is the thing everyone would rely on.

Nothing in this course grades a held item, a fitted constant or a film coefficient. That is a consequence of the same honesty rather than a separate policy: a number nothing can validate is a number nobody should be marked against.
