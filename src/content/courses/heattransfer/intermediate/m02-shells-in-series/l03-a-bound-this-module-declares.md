# A bound this module declares

The shell count in this module stops at six. That limit is declared by the module itself. It is not a published limit, and the refusal that enforces it says so in its own text, which matters because a reader is entitled to know which of the numbers constraining them came out of the literature.

## The refusal, and the reason inside it

Asked for seven shell passes in series, the engine refuses. Its message says that seven shell passes in series is outside the declared bound of 1 to 6, that the bound is a design limit declared by this module rather than a published one, and that it exists because F approaches 1 as the shell count grows, so an unbounded box makes any duty reachable by typing.

That last clause is the argument. The correction climbs toward one as shells are added, so a box with no ceiling hands a user a way to make any duty look reachable by raising a number on a screen. The bound stops arithmetic from standing in for steel.

## A bound is a labelled decision

There is a habit here that goes beyond shell counts. When a tool constrains you, ask where the constraint came from. A published limit is a statement about the world and you argue with it by finding better data. A declared limit is a statement about the tool and you argue with it by reviewing the declaration.

This module makes that distinction visible in two places. It carries a declared bounds table, separate from anything measured, and its refusal messages name the bound as declared when they enforce one. A limit that hides in a comparison somewhere in the code cannot be argued with at all, because nobody can find it.

There are two entries in that table and both come up in this tier. The shell count stops at six, for the reason above. The other is the margin at which the module is willing to name a controlling resistance, declared at 10 percent, and that one is the subject of a later module here. Both are reporting decisions rather than physics, and both are labelled.

## The count is whole

The second refusal on this door is about the shape of the number rather than its size. Asked for 2.400000 shells, the engine refuses: shells come in whole numbers and 2.4 is not one. The engine will not round for you: 2 and 3 shells give materially different F. State one.

Read the last sentence and then read the figures behind it. At the duty from the previous lesson, two shells give 0.800677 and three give 0.920456. A tool that quietly rounded 2.400000 down would hand back the first of those, and a tool that rounded up would hand back the second, and in neither case would the user know a choice had been made on their behalf. So the engine makes the caller make it.
