# A fill height that cannot be negative

Every engine in this course has a set of inputs that are arithmetically fine and physically impossible. The tank capacity function has the simplest one in the whole wave, and the way it handles it is the pattern for everything refused later in this tier.

## The refusal, in the engine's own words

Ask the engine for the capacity of a tank at a fill height below zero and it returns this:

> a fill height cannot be negative: a tank does not hold less than nothing

Quote a refusal exactly as the engine writes it, because that string is what a user reads on the screen. A learner taught a paraphrase will not recognise the real message when it fires.

## Why arithmetic alone will not stop this

The volume of a cylinder is a cross section times a height. Hand that relation a negative height and it returns a negative volume without complaint, because multiplication has no opinion about physics. On this tank the cross section is 3058.1520 ft2 and the conversion is 5.614583333333333 cubic feet in a barrel, and both would carry a negative height straight through to a negative inventory.

A negative inventory is rarely caught downstream either. It is a number. It sums, it averages, it plots, and it can cancel a real volume somewhere else in a total. That is the shape of defect a guard at the input exists to stop, and it is why the guard belongs in the engine rather than in the screen that calls it.

## A refusal is a result

The important thing about the message above is that it is an answer. The engine does not return a zero, and it does not return a blank. It returns a reason. Those three responses look similar on a screen and they are not the same thing at all. A zero says the tank holds nothing. A blank says the tool broke. A reason says the question was malformed and tells you which part of it was.

This tier meets several more of these, and one of them refuses to convert a figure the engine has already computed. The tank capacity refusal is the plain introduction, because its reason is obvious.

## Where it is counted

This refusal is not a one-off. The digest counts the refusals it calls and proves across all three engines, and tankCapacity contributes one of them, listed as the refusal on a fill height below zero. The final module of this tier reads that register function by function.
