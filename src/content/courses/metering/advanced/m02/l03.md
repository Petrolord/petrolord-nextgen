# The minimum plate is a stated input

On this tank four of the five courses are set by neither the product nor the water. They are set by a floor, and where that floor comes from is a question worth asking before you build anything on the answer.

## The floor in force

The minimum shell plate thickness in force on this tank is 0.187500 in. Four of the five courses are governed by it, and when it governs the engine says so:

> neither the product nor the water test needs this much plate: the stated minimum of 0.1875 in governs this course

That message is doing something useful. A thickness that comes back higher than both computed conditions looks wrong until you know why, and a reader with only the number has no way to tell a floor from an error in the relation.

## Where the value comes from

The engine is equally direct about the provenance of the floor:

> a stated input. API 650 bands the minimum shell plate thickness by tank diameter and this package does not carry that band table, so this value is the caller's and not the standard's

Read that carefully, because it changes what the result means. The engine is not claiming that 0.187500 in is the standard's minimum for a tank of this diameter. It is reporting the value it was handed. The band table that would turn a diameter into a minimum is one of the fifteen items the final module of this tier registers as not carried.

## What a stated input obliges you to do

A stated input is a shared responsibility. The engine applies it faithfully and names it in the result, and neither of those makes it right for your tank. Somebody has to open the standard, read the band for the diameter in question, and confirm the figure being passed in belongs there.

The alternative pattern is worse and is common. A package carrying a hard-coded minimum with no band table and no note produces the same thickness and looks authoritative doing it, and nothing on the screen tells a reader that the floor was somebody's assumption. Here the result names the value in force, so a reviewer can check it in one line.

## Why the floor cannot be ignored

The minimum exists for reasons the hoop stress relation knows nothing about. Handling, welding, corrosion allowance and the practicalities of erecting a shell all put a lower limit on plate. On the upper courses of this tank the computed thicknesses at both conditions fall below the floor, which is exactly the situation the floor is for.

So on this tank one course is governed by the hydrostatic test and four by a value the package took as an input. Reading that as five courses of computed thickness misreads four of them.
