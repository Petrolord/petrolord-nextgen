# Cumulative from the top

Why the through-bore is a running minimum, and what the running version tells you that the headline does not.

{{panel:cd-clearance-explorer}}

## The running minimum

For each component in order from the top, the cumulative minimum is the smallest inside diameter of that component and everything above it.

The last value is the headline through bore. The intermediate values are what a tool can reach.

## It can only step down

Like the governing drift in the clearance check, this is monotone. Each cumulative value is the previous one or smaller, never larger.

The reason is the same. A tool cannot un pass a restriction. If it got through a nipple at two thousand metres, everything it can reach below is limited by that nipple whatever the local bores are.

## What the running version answers

The headline says what can reach the bottom. The running version says what can reach any depth.

That is a genuinely different question with practical consequences. A gauge that will not pass the no go nipple can still be set anywhere above it, which in the published string is more than ninety nine percent of the well. A completion with a small restriction at the very bottom is not a completion with poor access.

## Reading the profile

Plot the two columns together in the panel: each component's own bore, and the cumulative minimum. The own bore jumps up and down as equipment comes and goes. The cumulative minimum is a staircase going one way.

Where the two coincide, that component is the current restriction. Where they differ, something above is tighter and the component's own bore is irrelevant to access.

In the published string the two coincide at only three components out of thirteen. Ten of the thirteen have bores that never limit anything.

## Why the engine keeps the whole profile

Because the headline is one number and the decision usually needs two: what is the restriction, and where does it start applying. Both come from the running form, and neither can be recovered from a single minimum.
