# An extreme is not an extent

A minimum tells you how small, and it does not tell you how much. The two questions need different calculations.

{{panel:cd-clearance-explorer}}

## The distinction

The through bore is an extreme: the smallest value anywhere. The extent is a length: how much of the string a given restriction governs.

A running minimum gives the first for free and gives the second only if you go looking.

## Why it matters here

The published string's two restrictions are of wildly different extents. One governs almost the whole string and one governs a few metres, and they are reported by the headline as if only the second existed.

A reader told the through bore is two point six three five inches will reasonably assume the string is a two point six three five inch bore string. It is not. It is a two point seven five inch string with three and a half metres of something smaller at the very bottom.

## The general shape of the error

This is a specific case of a general reporting problem. An extreme value summary is correct and can be badly misleading, because it says nothing about how typical the extreme is.

The same shape appears elsewhere in this course. The tightest clearance in a string is an extreme, and knowing that twelve of thirteen rows clear by ten times as much is the extent that gives it meaning.

## Computing the extent

Walk the running minimum and attribute each component's length to whichever component is currently the restriction. Sum by name.

That is a handful of lines of code, it needs no new inputs, and it turns a single misleading number into a description of the string.

## When the extreme is the right summary

When the operation cares only about reaching the bottom. A plug set in the no go nipple has to pass the no go nipple, and the fact that the rest of the string is roomier is of no help.

So the headline is not wrong. It is the right answer to one question and it is routinely read as the answer to a different one.

## The habit

When a summary is a minimum or a maximum, ask over how much. If the answer is a small fraction, report both numbers.
