# The through-bore

The second fit question, asked in the opposite direction from the first.

{{panel:cd-clearance-explorer}}

## The question

Once the completion is in the hole, what can be run inside it.

That is not the same question as whether the string went in, and it does not have the same answer. Getting the string down is about outside diameters against casing bores. Getting a tool through is about inside diameters against each other.

## Why it matters

Almost everything that happens to a well after it is completed goes through the tubing. Production logging, pressure gauges, plugs, chokes, shifting tools for the sliding sleeve, gas lift valve change outs, scale removal, perforating on coiled tubing.

Every one of those has a maximum outside diameter, and the through bore is what that has to be compared against. A completion with a restriction nobody accounted for is a completion where a routine intervention becomes a workover.

## The definition

The through bore is the smallest inside diameter along the string, from the top down.

Stated that way it sounds like a single minimum over the component list, and for the headline number it is. The useful version is a running minimum, which gives the smallest bore down to each depth rather than only for the whole string, and that is what the engine computes.

## The published string

Its through bore is two point six three five inches, about sixty seven millimetres, and it is set by the no go nipple near the bottom.

The tubing bore is two point nine nine two inches. So the completion, which is made almost entirely of pipe with a bore of two point nine nine two, is advertised at two point six three five, because of one component less than half a metre long.

## The asymmetry with clearance

Run in clearance has a physical asymmetry too, but the through bore's is starker. A component's clearance is compared against the tightest thing above it, which is a property of the well. A tool's access is limited by the tightest thing above it in the string, which is a property of the completion the designer chose.

The first is inherited. The second is a decision, and it can be revisited.
