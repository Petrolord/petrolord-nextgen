# What this course does not model

The physics that is absent, and what including each would require.

## Deviation and doglegs

There is no survey. Every depth is measured depth and no calculation knows the inclination.

Including it would need the survey and would change the clearance check materially: a rigid component through a bend needs more room than its diameter, growing with the square of its length and with the curvature. It would also allow a running load calculation.

## Running mechanics

No friction, no hook load, no drag. A completion that fits may still not go, particularly in a horizontal well where the string has to be pushed.

Including it would need the survey, a friction factor and the string weight, which is the Torque and Drag course's apparatus.

## Thermal and pressure loads

The length changes are inputs. Nothing here computes them.

Including them would need a flowing temperature profile, a pressure profile and a fluid density, which is the Casing and Tubing Design course's apparatus.

## Buckling

A string in compression buckles helically and shortens further, nonlinearly. That interacts directly with space out, because buckling changes the length change that the space out has to absorb.

Including it would need the axial force distribution, which needs the loads above.

## Time

Nothing here ages. Scale, corrosion, elastomer degradation, wear from wireline runs and thermal cycling are all absent.

Including any of them would need a service life model and, realistically, field data.

## Flow

No rate, no pressure drop, no erosion velocity. The flow couplings in the string are modelled as short pieces of steel and the reason they exist is not computed.

## The pattern

Each absent item needs an input the model does not carry, and each of those inputs belongs to a course that does carry it. The academy is arranged so that the boundaries between models are the boundaries between courses.

## Exercise

For each of the six absences, name the input required and the course that supplies it.

Then say which one interacts most strongly with the results of this course, and how.

Finally, say which you would add first if this engine were to be extended.
