# What each piece is for

The fourteen equipment types in one pass, with the operational reason each one exists.

{{panel:cd-string-explorer}}

## Protection

A flow coupling is a short heavy walled joint of the same nominal size, placed immediately above and below anything that disturbs the flow. Turbulence downstream of a restriction erodes the pipe, and a flow coupling puts a thick wall where the erosion will be.

A blast joint is the same principle against a different attack: it goes opposite a perforated interval where produced fluid jets sideways onto the string.

## Control

A surface controlled subsurface safety valve is the well's fail safe. Hydraulic pressure from a control line holds it open, and if the line loses pressure the valve shuts. It is set a few hundred metres below surface so that it is below anything a surface incident could reach.

A sliding sleeve opens a port between tubing and annulus, shifted by a wireline tool. A side pocket mandrel holds a gas lift valve in an offset pocket, so the valve can be pulled and replaced without pulling the string.

## Access

A landing nipple is a machined internal profile that a lock mandrel latches into, so a plug, a gauge or a choke can be set at a known depth. An X profile is selective, meaning tools can be run past it to a deeper one of the same size. An XN profile has a no go shoulder, so a tool of the wrong size stops there.

A wireline entry guide at the bottom of the string is a bell mouth that guides a tool coming back up from below back into the bore.

## Isolation and movement

A production packer seals the tubing to the casing, so that produced fluid is contained by the tubing and the annulus above it can be left full of packer fluid at whatever pressure the design wants.

An expansion joint or a polished bore receptacle absorbs the length change that heating and cooling produce, so that the length change does not turn into a load on the packer.

## Conduit

Tubing carries the fluid. A perforated joint lets the fluid in when the bottom of the string is plugged, which is the usual arrangement below a packer.
