# Reading a tally

How to look at a finished completion tally and see what it is telling you.

{{panel:cd-string-explorer}}

## Read the length distribution first

Open the published string in the panel and look only at the length column. Four rows carry almost the whole string and nine rows carry about thirteen metres between them.

That distribution is normal and it is worth internalising, because it means that when a tally looks unusual, the unusual thing is nearly always in the short rows. A tubing length changes the depth of everything below it. An equipment length changes almost nothing about the depths and everything about the fit.

## Then read the diameters

Scan the outside diameter column for the largest values, and the inside diameter column for the smallest. Those two scans find the components that will fail a clearance check and the components that will set the through bore, before you run either check.

In the published string the widest bodies are the safety valve, the side pocket mandrel and the packer. The narrowest bores are the safety valve, the sliding sleeve, the packer and the no go nipple. Three names appear on both lists.

## Then read the order

The order matters for two reasons. A component's clearance is checked against everything above it, so a wide body low in the string is harder to run than the same body high in it. And the through bore is a running minimum from the top, so a narrow bore early in the string affects access to everything below it.

Read the order and you can predict roughly what the two checks will say, which means you can tell when they say something surprising.

## What a tally cannot tell you

It cannot tell you the well is deviated, because there is no survey in it. It cannot tell you the string is heavy, because there is no weight in it. It cannot tell you what the completion is for, because there is no reservoir in it.

Those are not omissions. A tally is a list of steel and its depths, and every question this course asks can be answered from it plus a casing program.

## The habit worth forming

Before running any check, predict what it will say. Three predictions from the three scans above, written down, take a minute.

Then run the check. When it agrees, you understand the string. When it disagrees, you have found either an error or something interesting, and both are worth the minute.

## Exercise

Do the three scans on the published string and write down three predictions: which component will be tightest, which will set the through bore, and which two are widest.

Then run the checks in the panel and compare.

Note any prediction you got wrong and say what you had failed to account for.
