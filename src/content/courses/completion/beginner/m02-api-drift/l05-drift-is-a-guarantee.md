# Drift is a guarantee

What a drift entitles you to, what it does not, and where in a real string the guarantee stops applying.

{{panel:cd-string-explorer}}

## What it entitles you to

If a joint has been drifted to a given diameter, a rigid cylinder of that diameter and the mandrel length will pass through that joint. That is a hard guarantee backed by a physical test on that particular joint.

Everything this course does with clearance rests on it. When the engine says a component clears the casing by five millimetres, it means the component is five millimetres smaller than a size that is guaranteed to pass.

## What it does not entitle you to

It says nothing about anything longer than the mandrel. A twelve inch mandrel says nothing about a forty foot rigid assembly through a doglegged joint.

It says nothing about the couplings, which are drifted separately. It says nothing about the casing after it has been in the ground, where scale, wax, corrosion product and a mechanically deformed section are all possible. It says nothing about a joint that has been reamed, milled or damaged during running.

And it says nothing about the pipe not in this string. A liner lap, a tie back seal, a wellhead spool and a tubing hanger all have their own bores and none of them is in the casing drift table.

## Where the guarantee stops in practice

The honest statement is that drift is a guarantee about new pipe in the rack. What is in the hole three years later is a different object.

That is why a drift run is done before a workover: a physical mandrel or a gauge ring on wireline, through the actual well, before anybody commits a tool string to it. The catalog value tells you what to expect. The drift run tells you what is there.

## Reading a clearance in that light

So the clearances in this course should be read as clearances against the best case. A row that clears by five millimetres has five millimetres against the manufacturing guarantee, and less than five against whatever is actually down there.

That is the argument for a warn margin, which the next tier introduces. Zero clearance against a guarantee is not zero clearance in a well. It is negative.
